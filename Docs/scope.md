# Krypton — Scope

## What Krypton is

A workout tracker for home (bodyweight, dumbbell) and gym workouts.
Mobile-first (Flutter), with a .NET 10 API, PostgreSQL, and later a React web app.
First user: me.

## MVP

I can open the app at the gym, log today's sets, and see what I lifted last time.
